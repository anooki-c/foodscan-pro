## P01 首页

#### 目标
让用户 5 秒内进入分析。最多 4 个核心入口，少文字。

#### 入口（依据 PRD §5.2）
食品数据库开启时显示：
1. 扫描条形码
2. 拍摄配料表
3. 上传图片
4. 输入配料文字

数据库未开启时隐藏"扫描条形码"，但保留后 3 个入口（"数据源不可用"提示置灰）。

#### 交互细节
- 入口卡 hover（PC）上浮 2px，阴影加深。

## P02 条形码扫描（移动端独占）

#### 流程
1. 进入页面 → 唤起后置摄像头 → 全屏取景框。
2. 居中显示 80% 宽 × 30% 高的取景区，覆盖条形码区域。
3. 扫描成功 → 显示识别到的数字 → 进入 P03（命中数据库）或 P01 选择其他入口（未命中）。
4. 失败：手动输入条形码。

#### 取景框
- 4 个角标记，蓝紫渐变。
- 上方提示：`将条形码对准取景框`。
- 下方：`[手动输入]` + `[闪光灯]`。

#### 主体结构

```
┌────────────────────────────────────────┐
│ 食品名称：xxx（如有）                  │
│ 数据来源：xxx · 更新时间：xxx          │
├────────────────────────────────────────┤
│ [原始图片预览]  [置信度条]              │
├────────────────────────────────────────┤
│ 配料表（共 N 项）        [+ 新增]      │
│ ┌────────────────────────────────────┐ │
│ │ 01  小麦粉       [天然][高可信] ⋯  │ │  可拖拽
│ │ 02  白砂糖       [天然][高可信] ⋯  │ │
│ │ 03  植物油       [天然][高可信] ⋯  │ │
│ │ 04  乳粉  ⚠建议确认 [天然][中可信] ⋯ │ │
│ │ 05  山梨酸钾      [添加剂][高可信] ⋯ │ │
│ └────────────────────────────────────┘ │
├────────────────────────────────────────┤
│       [取消]              [确认并分析] │
└────────────────────────────────────────┘
```

#### 编辑交互（BottomSheet）

```
┌─ 编辑配料 ──────────────────┐
│ 当前：山梨酸甲              │
├─────────────────────────────┤
│ 推荐结果：                  │
│  山梨酸钾      匹配度 96%   │
│  山梨酸钠      匹配度 88%   │
│  山梨酸钙      匹配度 81%   │
│  山梨酸        匹配度 76%   │
│  山梨酸酯      匹配度 71%   │
├─────────────────────────────┤
│ 或直接输入：                 │
│ [_________________]          │
├─────────────────────────────┤
│  [取消]   [使用当前输入]   │
└─────────────────────────────┘
```

#### 移动端交互
- 拖拽手柄在左，删除/编辑按钮在右。
- 拖动时整行透明度 0.7，落点显示蓝色横线。
- 序号始终可见，使用 `var(--font-mono)`。

#### PC 端交互
- 拖拽改用上下箭头按钮（点击 1px 移动），可访问性更好。
- 编辑直接在行内打开弹层（不必每次开 BottomSheet）。

#### 异常
- OCR 完全失败：`暂时无法识别图片` + `[重新上传] [手动输入]`。
- 单项低置信度：在该项左侧显示黄色 `⚠` 图标 + 行内 `建议确认` 文字。
- 数据库无匹配：`未找到相似成分`（不阻止流程，可使用当前输入继续）。

#### 关键约束
- 环形图下方必须配图例，不靠颜色识别。
- 配料顺序 = 用户确认后顺序，**禁止重排**。
- 添加剂详情、过敏原详情、成分详情均通过 BottomSheet 打开。
- AI 解读默认折叠/可展开，刷新会重新调用。

#### 移动端调整
- 配料表为单列，每项点击全行可触发 BottomSheet。
- 数字概览改为 4 个小卡（配料数 / 天然 / 加工 / 添加剂）。
- 过敏原卡片全宽。

## P05 多食品对比

#### 加入对比入口
- P04 底部 [加入对比] 按钮（最多 5 个，达上限禁用并提示）。
- 历史记录列表项右侧 [+] 加入。

#### 对比页结构

```
┌────────────────────────────────────────┐
│ 配料对比（3 / 5）        [清空]        │
├────────────────────────────────────────┤
│  [A: 燕麦奶] [B: 豆浆] [C: 杏仁奶]     │
│  [+ 添加食品]                          │
├────────────────────────────────────────┤
│ 类型统计                                │
│ ┌──────────┬────┬────┬────┬────┬────┐  │
│ │ 配料数   │ 12 │ 15 │ 11 │ -- │ -- │  │
│ │ 食品添加剂│  3 │  5 │  2 │ -- │ -- │  │
│ │ 防腐剂   │  1 │  2 │  0 │ -- │ -- │  │
│ │ 增稠剂   │  1 │  1 │  1 │ -- │ -- │  │
│ │ 潜在过敏原│  2 │  2 │  1 │ -- │ -- │  │
│ └──────────┴────┴────┴────┴────┴────┘  │
├────────────────────────────────────────┤
│ 配料顺序对比（按各自顺序）              │
│ ┌─────┬─────────┬─────────┬─────────┐  │
│ │ 序  │   A     │   B     │   C     │  │
│ ├─────┼─────────┼─────────┼─────────┤  │
│ │ 01  │ 小麦粉  │ 大豆    │ 水      │  │
│ │ 02  │ 白砂糖  │ 白砂糖  │ 杏仁    │  │
│ │ 03  │ 植物油  │ 植物油  │ 白砂糖  │  │
│ │ 04  │ 乳粉    │ 黄原胶  │ 黄原胶  │  │
│ │ 05  │ 黄原胶  │ 山梨酸钾│  —      │  │
│ └─────┴─────────┴─────────┴─────────┘  │
│  说明：共同 / 独有 / 缺少 / 位置变化   │
├────────────────────────────────────────┤
│ 底部说明：                              │
│  配料表顺序可用于观察配料组成差异，但   │
│  不能仅凭顺序确定具体含量。             │
└────────────────────────────────────────┘
```

#### 标记规则（PRD §15.4）
- 共同：默认文字色。
- 独有：背景 `--color-status-info-bg`，前缀 `[A 独有]`。
- 缺少：`—` 灰色 + `[B 缺此项]` 角标。
- 位置变化：右上角小徽章 `[位置变化：A05 → B03]`。
- 配色禁用红绿表达"好坏"。

#### 移动端
- 表格区域横向滚动，顶部固定 Tab 让用户快速跳列（PRD §15.6）。
- Tab：`← A | B | C | D | E →`。

## P06 历史记录

#### 来源
- 本地存储（LocalStorage / IndexedDB），无账号同步。
- 保存字段：食品名称、条码（如有）、分析时间、配料及确认结果、分析结果摘要、图片（按隐私策略）。

#### 列表结构
- 移动端：单列卡片，含缩略图 + 名称 + 时间 + [详情] [+] [删除]。
- PC 端：4 列网格。
- 顶部：`[搜索]` `[过滤]` `[排序：时间/名称]`。

#### 操作
- 点击卡片 → P04。
- 长按 / 右键 → [加入对比] [删除] [重新分析]。
- 删除时同时删除对应图片（PRD §16）。

## 全局设计自检

每个页面交付前对照 `docs/01-design-reconciliation.md` §8 自检清单。
